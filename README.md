# Alexis Gómez — Portfolio v3

Next.js portfolio with project detail pages, galleries, certificates and downloadable papers/CV.

## Edit projects
All project content is in `data/projects.ts`. Add/remove/edit one object, then commit.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Push to `alexenmgo/portfolio`; Vercel will redeploy automatically once you replace the repository contents.

## Privacy
Public screenshots included here were selected/sanitized for portfolio use. Re-check any new internal screenshots before publishing.

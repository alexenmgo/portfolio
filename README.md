# Alexis Gómez — Portfolio v2

A data-driven Next.js portfolio ready for GitHub + Vercel.

## Easy maintenance
All project content lives in `data/projects.ts`. Add/remove/reorder projects there. Change `section` to `featured`, `internal`, or `research`.

## Before publishing
Replace `YOUR_EMAIL` and `YOUR_LINKEDIN` in `app/page.tsx`.

## Dashboard screenshots
Add these files to `public/projects/`:
- `bi-compliance.jpg`
- `bi-investor.jpg`
- `bi-hr.jpg`

## Run
```bash
npm install
npm run dev
```

## Deploy
Push to GitHub, import the repository in Vercel, and deploy with the default Next.js settings.

## Privacy
Do not publish client data, credentials, confidential thresholds, or proprietary source code. Sanitize screenshots before uploading.
